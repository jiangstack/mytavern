# 我的酒馆 · My Tavern

<p align="center">
  <b>一个可以使用 AI 创作小说、和小说人物聊天的 Android App</b><br>
  <b>没有复杂的设置，我称之为“我的酒馆”</b>
</p>

---

## 🌟 功能特性

> **标签**：纯文本 · LLM RPG · 小说创作 · 互动故事 · 生活模拟 · Android

- **🤖 多模型兼容**
  - 支持 OpenAI 格式兼容的 LLM API
  - 可自定义 Base URL、API Key、模型名称与参数

- **👤 角色管理**
  - 创建、编辑、删除角色卡
  - 支持 AI 辅助生成角色设定
  - 角色头像、性格描述、背景故事一目了然

- **📖 世界书**
  - 简单的世界书系统（本质是系统提示词管理）
  - 为你的故事和聊天构建统一的世界观

- **💬 单聊 / 群聊**
  - 与单个角色进行沉浸式对话
  - 群聊支持多角色同时在线
  - `@角色名` 指定回复对象
  - 接话模式让对话更自然流畅
  - 双击角色名可触发该角色继续发言

- **🎮 互动故事** *(新增)*
  - LLM 驱动的互动式故事体验
  - 玩家可扮演任意角色，由 AI 讲述者推进剧情
  - 支持自定义行动输入和预设选项
  - **检查点/存档系统**：随时保存故事进度，支持回滚重玩
  - **图像生成**：AI 生成场景插图，增强沉浸感
  - 可配置提示词管理，定制讲述者风格
  - 角色状态、物品、环境实时追踪
  - 对白内容智能着色，提升阅读体验

- **🏘️ 小镇模拟** *(新增)*
  - 类《模拟人生》的生活模拟玩法
  - NPC 自主日程系统：角色按照行动表在小镇中生活
  - 时间推进机制：手动推进，观察小镇变化
  - **相遇检测**：同一地点的角色自动触发场景
  - **AVG 式场景播放**：沉浸式观看角色互动
  - 玩家可扮演角色，亲自参与小镇生活
  - 关系系统：角色间好感度与关系描述动态演化
  - 记忆系统：角色记住近期经历和重要事件
  - 世界事件注入：玩家可手动"搞事"改变小镇走向
  - 快照存档：跨天自动存档，支持回滚重掷

- **✍️ 小说创作**
  - AI 辅助续写与改写
  - 智能体点评和创作辅助
  - 章节管理与大纲折叠编辑
  - 提示词管理与快速复用
  - 人物对白智能着色
  - 人物物品管理功能

- **🌙 其他特性**
  - 黑夜主题支持
  - 用量统计（Token 消耗）
  - 请求日志记录与查看
  - 数据导出 / 导入（`.db` 数据库备份）
  - 本地离线数据存储，隐私优先

## 🛠 技术栈

| 层级 | 技术 |
|---|---|
| **UI** | Jetpack Compose + Material 3（纯 Compose，无 XML Layout） |
| **架构** | MVVM + Repository 模式 |
| **依赖注入** | 手动 DI（`AppContainer.kt`） |
| **导航** | Compose Navigation |
| **数据持久化** | Room + SQLite（Schema 导出至 `app/schemas`） |
| **网络请求** | Retrofit + OkHttp + kotlinx.serialization |
| **图片加载** | Coil |
| **异步** | Kotlin Coroutines + Flow |
| **本地配置** | DataStore Preferences |

## 📖 使用指南

### 1. 配置 LLM API

首次使用请进入「设置 → LLM 配置」，填入：

- **Base URL**：例如 `https://api.openai.com/v1/`
- **API Key**：你的 API 密钥
- **模型名称**：例如 `gpt-4o-mini`、`claude-3-5-sonnet-20241022`

### 2. 创建角色

进入「角色」页面，点击右下角按钮创建角色。你可以：

- 手动填写角色设定
- 使用 AI 辅助生成角色背景、性格、开场白

### 3. 开始聊天

进入「聊天」页面创建会话，选择单个或多个角色即可开始对话。群聊中：

- 输入 `@角色名` 让指定角色回复
- 不 @ 任何人时，App 会自动选择“接话”角色
- 双击 AI 消息中的角色名可再次触发该角色发言

### 4. 创作小说

进入「小说」页面创建小说：

- 关联世界书和角色
- 添加章节和大纲
- 在章节编辑器中使用 AI 续写正文
- 流式生成的内容可「采纳」或「丢弃」

### 5. 互动故事

进入「互动」页面创建互动游戏：

- 选择参与角色和扮演角色
- 配置讲述者风格和故事背景
- AI 讲述者会推进剧情并提供行动选项
- 可以输入自定义行动或选择预设选项
- 使用检查点功能保存进度，支持回滚重玩
- 开启图像生成可获得 AI 绘制的场景插图

### 6. 小镇模拟

进入「小镇」页面创建小镇：

- 设置小镇地点和成员角色
- 推进时间，观察 NPC 按日程生活
- 同一地点的角色会自动触发互动场景
- 可扮演某个角色亲自参与小镇生活
- 使用「搞事」按钮注入世界事件改变走向
- 查看小镇日志了解完整故事线

### 7. 数据备份

通过「设置 → 数据管理」可以导出或导入 `.db` 数据库文件，方便备份与迁移。
